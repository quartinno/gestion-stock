# Public Images Directory

This directory contains images that are publicly accessible via direct URL paths.

## Usage

Place images here when you need to:
- Reference them via public URLs
- Use them in meta tags or SEO
- Access them without importing in JavaScript

### Example Usage:

```jsx
// In your React component
<img src="/images/logo.png" alt="Logo" />

// In HTML meta tags
<meta property="og:image" content="/images/og-image.jpg" />
```

## File Structure

Organize your images by type:
- `logos/` - Company and brand logos
- `products/` - Product images
- `banners/` - Hero images and banners
- `icons/` - Icon files
